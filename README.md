# COVOIT CI — prototype web V0.2

Ce dossier contient le prototype de démonstration COVOIT CI.

## Publication sur GitHub + Vercel

1. Sur GitHub, créer un nouveau dépôt nommé `covoit-ci`.
2. Choisir `Public` ou `Private` (les deux conviennent pour cette vitrine), sans ajouter de README, licence ni `.gitignore` au départ.
3. Dans le dépôt, choisir **Add file > Upload files**.
4. Déposer `index.html`, puis valider avec **Commit changes**.
5. Sur Vercel, choisir **Add New > Project**, importer le dépôt `covoit-ci`.
6. Pour ce site statique, laisser les réglages de build par défaut si Vercel ne demande rien, puis cliquer **Deploy**.

## Limites à afficher clairement

Ceci est un prototype local de démonstration : la recherche de trajets est simulée, les trajets publiés restent dans la session du navigateur, et il n'y a ni comptes utilisateurs, ni réservations réelles, ni base de données, ni géolocalisation, ni paiement, ni notifications.

Ne pas présenter ce prototype comme un service de covoiturage opérationnel.
